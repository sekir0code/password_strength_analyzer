# 🔐 Password Strength Analyzer

A simple Python program that analyzes the strength of a password and gives suggestions for improving it.

This project was created while practicing my Python development environment, Git, and GitHub.

## Features

The program checks whether a password contains:

- At least 8 characters
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

It then gives the password a score from 0 to 5 and displays its strength.

## Example

Enter a password:

Monkey123!

Password Analysis:

8+ characters: ✓  
Uppercase: ✓  
Lowercase: ✓  
Number: ✓  
Special character: ✓  

Score: 5/5

Strength: VERY STRONG
